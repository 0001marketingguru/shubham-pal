## 🎨 3. Visual Style Guide & System Taste Dials

To enforce an editorial, high-ticket aesthetic from day one, override all default frontend templates using these precise design configurations:

### 🎛️ Configuration Dials
* **DESIGN_VARIANCE = 8** (Mandate high layout asymmetry; utilize overlapping rows, unexpected container breaks, and editorial flows instead of boring, centered corporate safety grid boxes).
* **VISUAL_DENSITY = 4** (Mandate expansive, luxurious whitespace and massive padding blocks to let primary visual assets breathe and imply exclusivity).
* **MOTION_INTENSITY = 4** (Animations must be subtle, unhurried, hardware-accelerated, and strictly purposeful).

### 🔤 Typographic Matrix
* **Display Typography (Headings H1, H2, H3):** Uppercase style using a heavy geometric sans-serif (e.g., *Oswald* or *Clash Display*). Kerning must be clamped to `tracking-[-0.03em]` with minimized line-heights to maintain a dense, commanding footprint.
* **Prose Typography (Body Copy, Lists, Content Blocks):** High-readability modern sans-serif (e.g., *Inter* or *Manrope*). Set text size to a minimum of `16px` with an open `leading-relaxed` (1.6 minimum) line-height to eliminate cognitive fatigue during reading.

### 🚫 Strict Visual Negative Constraints
* **No Decorative Hype:** Completely ban cartoon icons, playful vector shapes, floating animations, or generic stock illustrations. Use crisp canvas structures, clean metadata blocks, and real portrait boundaries.
* **No Elevation Drop Shadows:** Avoid blurry or soft CSS box-shadow structures. Isolate visual components cleanly using flat background shade shifts and crisp 1px structural lines.
* **Text Alignment Law:** Long blocks of prose copy must never be center-aligned. Always default to strong left-alignment (`text-left`) to optimize eye-tracking speeds for stressed readers.
* **The Conversion Accent Lock:** The primary brand action color must be reserved exclusively for high-intent conversion elements (primary submission CTAs, active input field focuses, live scarcity counters). It is strictly forbidden to use it ornamentally for background decorations or icons.

## 🏛️ 4. High-Converting Page Architecture Blueprint

Every individual service page must be modularly structured down a unified vertical scrolling track following this optimized layout chain. Build fold-by-fold, isolating exactly one section file per component inside `src/components/sections/`.

### Component 1: Above-The-Fold (ATF) Framework
* **The Hook:** Implement an outcome-driven value proposition framework rather than a generic descriptive title. *(e.g., Instead of "I do CRO consulting," force: "Skyrocket Your Funnel Conversion Rates Without Sacrificing Ad Spend.")*
* **Urgency Tracker Bar:** Place a subtle micro-text banner above or below the primary headline signaling scarcity. *(e.g., "Accepting only 2 elite entrepreneur portfolios for Q3")*
* **The ATF Call-To-Action:** Position a high-contrast CTA button clearly within one viewport scroll on mobile. Avoid generic strings like "Submit" or "Contact". Use highly descriptive, outcome-oriented button copy. *(e.g., "Book Your 15-Min Strategy Blueprint Call")*

### Component 2: The Trust Matrix & De-risking Section
* **Social Proof Anchors:** Embed an editorial "Social Proof Bar" directly beneath the ATF fold. Show off recognizable brand logos accelerated, clear statistics (e.g., "$X Generated in Pipeline"), or client faces with real star ratings.
* **The Step-Count Framework:** Visually break down how working with you works into a clear 3-step icon/number map to shatter processing friction:
    * *Step 1:* Book your diagnostic call.
    * *Step 2:* We audit your current stack.
    * *Step 3:* Deploy your custom GTM/AI infrastructure.

### Component 3: Bottom-of-Page Objection Handling
* **Snappy FAQ Module:** Implement a clean toggle accordion component right before the final CTA to aggressively crush objections around onboarding time commitments, technical dependencies, and pricing structures.
* **The "Repeated Action" Rule:** Never let an entrepreneur scroll to the dead-end of a page footer without a path. You must repeat the primary descriptive booking CTA at the absolute baseline of the page layout.

### Component 4: The Clean Booking Terminal (`/book-call`)
* **Traffic Leak Shield:** When a user arrives at the scheduler page, strip away the main header navigation menu and footer links completely to prevent traffic leaks and enforce 100% focus on completing the form.
* **Lead Capture UI:** Embed a minimalist, multi-step lead capture form alongside an explicit trust badge asserting your strict data security policy.
* **Curation Filter:** Force users to choose their primary operational bottleneck (AI, GTM, or CRO) before revealing open calendar slots.
